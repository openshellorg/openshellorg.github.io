## About

This repository publishes the organization root at `https://openshellorg.github.io/`. It is intentionally minimal:

- [`robots.txt`](robots.txt) — host-wide crawler policy with `Sitemap:` lines for known project Pages on this host
- [`sitemap.xml`](sitemap.xml) — sitemap index pointing at those project sitemaps
- [`index.html`](index.html) — brief pointer to the primary org site and docs

Docs for OpenShell live on the custom domain [docs.opensh.org](https://docs.opensh.org/) — they are **not** advertised from this host-root `robots.txt`. Project Pages that remain on `openshellorg.github.io` (for example ProHelp) are listed here.
